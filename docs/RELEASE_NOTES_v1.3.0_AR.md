# ملاحظات إصدار SmartSocial AI v1.3.0

يضيف هذا الإصدار دورة حياة حقيقية لسياسات Adaptive Memory؛ لم تعد السياسة
المتعلمة فعالة إلى أجل غير محدد.

## ما أضيف

- تحديد `valid_from` و`next_review_at` و`valid_until` عند اعتماد السياسة.
- مراجعة شهرية افتراضية بعد 30 يوماً مع مهلة تشغيل مقدارها 15 يوماً.
- اشتراط 8 منشورات مقيمة ومرتبطة بمعرف السياسة نفسها قبل اتخاذ قرار أداء.
- قرارات موثقة: `renew` و`modify` و`suspend` و`expire` و`insufficient_evidence`.
- تأجيل محدود عند نقص الدليل، ثم إيقاف السياسة بدلاً من إبقائها إلى الأبد.
- إنشاء إصدار `draft` جديد عند قرار التعديل، مع بقاء الاعتماد البشري إلزامياً.
- جدول `policy_reviews` لحفظ تاريخ الأدلة والقرار والنسخة والمراجع.
- Scheduler خفيف يفحص الاستحقاق يومياً، مع بقاء تاريخ الاستحقاق محفوظاً عبر إعادة التشغيل.
- ترحيل تلقائي آمن لأي سياسة نشطة قديمة لا تحتوي تواريخ مراجعة.
- API وواجهة لمراجعة السياسات المستحقة، مراجعة سياسة الآن، وقراءة السجل.

## ضمان علمي مهم

لا تُحسب كل المنشورات اللاحقة كدليل على سياسة ما. يحفظ التوليد معرفات السياسات
المطبقة داخل `GeneratedPost.memory_policy_ids`، ثم تُنقل إلى Evidence في
`context.applied_policy_ids`. لذلك يعتمد المراجع فقط المنشورات التي تلقت السياسة
فعلياً أثناء التوليد.

## التوافق

- لا تتغير سلطة Stable Brand DNA أو موجز الحملة.
- لا تزال كل سياسات Adaptive Memory توصيات مرنة افتراضياً.
- لا يوجد اعتماد أو نشر تلقائي.
- قواعد البيانات القديمة تُحدّث بإضافة جدول المراجعات من دون حذف البيانات.
- السياسة القديمة النشطة تُعطى جدول مراجعة مشتقاً من وقت اعتمادها أو آخر تحديث لها.

راجع `docs/POLICY_REVIEW_AND_PROJECT_FLOW.md` للتدفق الكامل ومسؤولية كل ملف.
