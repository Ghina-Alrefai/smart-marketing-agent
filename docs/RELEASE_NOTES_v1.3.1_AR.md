# SmartSocial AI v1.3.1 — ملاحظات الإصدار

تاريخ الإصدار: 2026-08-24

## النتيجة

هذه نسخة تثبيت وأمان كاملة. نجحت 53 حالة اختبار خلفية، وأعيد بناء
واجهة React على Linux من تثبيت npm نظيف.

## تحسين زمن إنشاء الحملة

- يُحمّل MiniLM وCLIP وملفا النموذج مرة واحدة في كل عملية API، ثم تعيد الطلبات
  والمحاولات استخدامها.
- أضيف preload عند إقلاع FastAPI، مع `scripts/preload_models.py` لتنزيل cache القرص مسبقاً.
- الأوزان تعاد إلى RAM بعد إعادة تشغيل الخادم، لكنها لا تعاد من Hugging Face ما دام
  cache القرص موجوداً.
- الحملة الصريحة تُفهم بقواعد محلية أولاً، فلا يُستدعى Gemini مرتين في طبقة المحادثة.

## الأمان وصحة API

- فرض ملكية الموارد على البراند والمنتج والخطة والمنشور والجدول والسياسة
  وجلسة المحادثة، مع بقاء صلاحية super-admin.
- منع HTML/SVG والصور التالفة والضخمة؛ الخادم يقبل PNG/JPEG/WebP مفكوكة فعلياً
  ويختار اللاحقة الآمنة.
- إعادة JSON 404/405 لمسارات API بدل إرجاع صفحة React بالخطأ.
- منع تشغيل الإنتاج بمفتاح JWT أو كلمة مرور المشرف الافتراضية. وضع production هو
  الافتراضي إذا غاب `.env`.
- منع حجز مهمتي توليد لنفس الخطة.

## الواجهة

- إزالة افتراض user/brand ID = 1.
- فصل جلسات المحادثة بين البراندات، وتصحيح React Query invalidation.
- إظهار أخطاء API ورقم التتبع، ومنع الضغطات المتكررة، وتصحيح إنشاء البراند/المنتج الجزئي.

## ملاحظة أمنية للتسليم

الملف المصدر المرفوع كان يحتوي مفتاح Google غير افتراضي داخل `.env`. هذا الملف وقيمته غير
موجودين في هذا الإصدار. يجب إلغاء/تدوير المفتاح القديم ثم وضع البديل في `.env` محلي جديد.

لتفاصيل الاختبار وحدود الخدمات الخارجية: `docs/QA_REPORT_v1.3.1.md`.
