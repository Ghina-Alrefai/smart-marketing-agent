# ملاحظات إصدار SmartSocial AI v1.2.0

هذه النسخة تجمع تعديلات الواجهات مع Brand DNA وAdaptive Memory ومسار الحملة
الموحّد، بعد إصلاح تعارضات الدمج.

## الإصلاحات

- إزالة نسختين متداخلتين من `campaign_pipeline` ومنع توليد المحتوى والصورة مرتين.
- الإبقاء على مسار واحد: فكرة → 3 مرشحين → اختيار → تصميم واحد → مراجعة بشرية.
- منع توليد شعار أو قالب داخل الصورة عند وجود قالب مرفوع، ثم تركيب القالب مرة واحدة.
- فرض تصميم هادئ بإطار واحد ومنع الشبكات وملصقات المواصفات والضجيج البصري.
- تسجيل استدعاءات Gemini النصية والصورية وربطها بالحملة في لوحة المراقبة.
- إضافة إعادة توليد آمنة للحملة الفاشلة مع حماية الاعتمادات وبيانات الأداء.
- إصلاح بناء React (تعارض استيراد ومتغير المستخدم) وإدراج الواجهة المبنية في الحزمة.
- ربط `VITE_GOOGLE_CLIENT_ID` بملف البيئة الموجود في جذر المشروع.
- حماية مسارات التطبيق بالمصادقة وإغلاق إنشاء المستخدمين على المشرف.
- إصلاح حذف الحملات المرتبطة بجدولة أو بيانات أداء مع تحديث عداد المنتجات.
- جعل تجميع الرسم اليومي في المراقبة متوافقاً مع SQLite وPostgreSQL.

## قبل التشغيل

1. انسخ `.env.example` إلى `.env`.
2. ضع `GOOGLE_API_KEY`.
3. لدخول Google، ضع القيمة نفسها في `GOOGLE_CLIENT_ID` و`VITE_GOOGLE_CLIENT_ID`.
4. غيّر `SECRET_KEY` و`ADMIN_PASSWORD` قبل أي تشغيل إنتاجي.
5. إذا عدّلت متغيراً يبدأ بـ `VITE_`، أعد بناء الواجهة.

الحزمة لا تتضمن `.env` أو قاعدة بيانات أو سجلات أو ملفات مرفوعة أو مجلدات
الاعتمادات؛ يشغّل `scripts/setup.ps1` أو `scripts/setup.sh` إعدادها محلياً.
